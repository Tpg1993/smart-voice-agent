### 7) MVP Plan and Timeline

**Phase 1 Focus:** Build the core engine securely in a single primary language for **one specific industry** (e.g., Salon/Spa bookings). Proving the end-to-end flow on one vertical is critical before scaling horizontally to complex industries like Healthcare (which requires strict HIPAA compliance).

| Timeframe | Key Milestone / Goal | MVP Features to Launch | Target Market / Language |
| :--- | :--- | :--- | :--- |
| **Month 1** | **Infrastructure & Core Engine** | Telephony gateway setup; Speech pipeline integration; Initial processing logic; Audio storage capability; CI/CD pipeline establishment. | English only (Internal Alpha) |
| **Month 2** | **Pilot-Ready (Single Industry)** | Calendar booking integration for a single low-risk industry (e.g., Salons); basic call transcript storage; internal notification system on call completion. | 1 Specific Region / English |
| **Month 3** | **Compliance & Security Hardening** | PII Redaction/Scrubber implementation (Mandatory before public release); automated testing of call flows; fallback logic for system failures. | Closed Beta Users |
| **Month 4** | **Outbound & Scale Expansion** | Automated outgoing calls (Reminders); Escalation logic to human operators; Post-call summary integration via SMS. | Adding Spanish / Regional Markets |
| **Month 5** | **Multi-Industry & Analytics** | Rollout to additional modules (Healthcare, Hotels, Real Estate); Dashboard UI for client success rates; Self-serve portal. | Global / Multi-lingual |
